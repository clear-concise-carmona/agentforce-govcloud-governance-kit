## What "Needs review" means in this repo's templates

`docs/action-inventory-template.csv` and other templates use a "Needs review" status for anything this repo's authors couldn't classify with confidence (for example, whether a specific Prompt Builder action's model call counts as inside or outside the authorization boundary, since that depends on which model is configured, which changes over time). "Needs review" is not a fourth confirmed category — it is an instruction to the user to go check, the same way "UNVERIFIED" is here.
